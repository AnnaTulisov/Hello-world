## How to Close a Pull Request Without Merging to Main

Sometimes you need to close a Pull Request without merging its changes into the main branch. Here's how to do it:

### Steps

1. **Navigate to the Pull Request**
   - Go to the repository on GitHub.
   - Click on the **Pull requests** tab.
   - Select the Pull Request you want to close.

2. **Close the Pull Request**
   - Scroll to the bottom of the Pull Request page.
   - Click the **Close pull request** button (without clicking "Merge pull request").

3. **Confirm**
   - The Pull Request will be marked as **Closed** and its branch will remain unmerged.
   - You can optionally delete the associated branch by clicking **Delete branch** after closing.

### Notes

- Closing a PR does **not** delete the branch or any commits — it simply stops tracking the proposed changes.
- You can reopen a closed Pull Request at any time if needed.
- If you want to discard the changes entirely, you can delete the branch after closing the PR.
